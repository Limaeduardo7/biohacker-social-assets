# Biohacker Foods — entrega pública de mídia social

Este repositório serve apenas imagens originais, aprovadas para entrega pública ao Buffer, em URLs HTTPS permanentes. O Google Drive é o arquivo privado canônico dos ativos e das evidências; o Notion é o calendário editorial canônico.

`canary/draft-check-v1.png` é uma imagem neutra para comprovar que `saveToDraft=true` salva rascunho privado e não agenda/publica. Não é conteúdo editorial.

Nenhuma imagem editorial deve ser adicionada aqui antes dos gates de fontes, direitos, revisão científica/regulatória e autorização de liberação. Nunca adicionar dados privados, credenciais ou arte de terceiro sem licença.
